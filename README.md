# 相片连续效果导入插件

## 功能介绍

这个Premiere Pro插件可以让您轻松导入连续的图像序列，每帧对应一张图像，从而快速创建相片连续播放的效果。

### 主要特点

- 通过文件夹形式显示和组织效果
- 支持从指定位置读取图像文件夹
- 每帧显示一张图像，自动创建连续的视觉效果
- 支持多种常见图像格式（JPG, PNG, TIFF等）
- 直观的界面，易于使用

## 使用方法

1. 在Premiere Pro中打开插件面板
2. 点击"选择文件夹"按钮，浏览并选择包含图像序列的文件夹
3. 插件将自动识别文件夹中的图像并按文件名顺序排列
4. 点击"导入序列"按钮，将图像序列作为单个视频片段导入到当前项目中
5. 导入的序列将出现在项目面板中，可以直接拖放到时间线上使用

## 图像要求

- 支持的图像格式：JPG, PNG, TIFF, BMP

## 自定义选项

- 帧率设置：可以指定导入序列的帧率（默认为项目帧率）
- 图像排序：可以按文件名、创建日期或修改日期排序
- 预览功能：导入前可预览图像序列效果
